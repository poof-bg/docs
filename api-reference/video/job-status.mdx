---
title: Get Video Job
description: "Check the status and progress of a video job"
api: "GET /video/jobs/{id}"
---

Returns the current state of a video job created with [Remove Video Background](/api-reference/video/remove-background), including its progress and, once it has completed, the URL to download the result.

This endpoint is free: polling does not consume credits.

## Request

<ParamField path="id" type="string" required>
  The job ID returned by `POST /video/remove` (starts with `vid_`).
</ParamField>

```bash
curl https://api.poof.bg/v1/video/jobs/vid_8f3a1c2e9b7d4a10 \
  -H "x-api-key: pk_your_api_key"
```

## Response

<ResponseField name="id" type="string">
  Job ID, prefixed with `vid_`.
</ResponseField>

<ResponseField name="status" type="string">
  One of `queued`, `processing`, `completed` or `failed`. See [Status lifecycle](#status-lifecycle).
</ResponseField>

<ResponseField name="progress" type="number">
  Fraction of the video processed so far, from `0` to `1`. It is `0` while `queued` and `1` once `completed`.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the job was accepted.
</ResponseField>

<ResponseField name="started_at" type="string | null">
  When processing began. `null` while the job is still `queued`.
</ResponseField>

<ResponseField name="completed_at" type="string | null">
  When the job reached `completed` or `failed`. `null` until then.
</ResponseField>

<ResponseField name="duration_seconds" type="number">
  Source video duration in seconds.
</ResponseField>

<ResponseField name="fps" type="number">
  Source frame rate.
</ResponseField>

<ResponseField name="width" type="integer">
  Source video width in pixels.
</ResponseField>

<ResponseField name="height" type="integer">
  Source video height in pixels.
</ResponseField>

<ResponseField name="frames" type="integer">
  Number of frames in the source video.
</ResponseField>

<ResponseField name="credits" type="integer">
  Credits charged for this job. Refunded automatically if the job fails.
</ResponseField>

<ResponseField name="format" type="string">
  The requested output format: `webm`, `mov`, `mp4`, `mask` or `png`.
</ResponseField>

<ResponseField name="status_url" type="string">
  URL of this job, the same one returned as `status_url` when the job was created.
</ResponseField>

<ResponseField name="result_url" type="string | null">
  URL to [download the result](/api-reference/video/download-result). `null` until the job is `completed`.
</ResponseField>

<ResponseField name="expires_at" type="string | null">
  When the result is deleted, 24 hours after completion. `null` until the job is `completed`. After this time the result URL returns `404 job_not_found`.
</ResponseField>

<ResponseField name="error" type="object | null">
  Set only when `status` is `failed`: an object with `code` and `message` describing why the job failed. `null` otherwise.
</ResponseField>

<ResponseField name="stats" type="object">
  Processing statistics. Present only when `status` is `completed`; absent otherwise.
  <Expandable title="properties">
    <ResponseField name="output_width" type="integer">
      Output video width in pixels: the source size capped at 1920 px on the longest side, aspect ratio kept.
    </ResponseField>
    <ResponseField name="output_height" type="integer">
      Output video height in pixels, capped in the same way.
    </ResponseField>
    <ResponseField name="processing_seconds" type="number">
      Wall-clock time spent processing the job, from `started_at` to `completed_at`.
    </ResponseField>
    <ResponseField name="matting_seconds" type="number">
      Time spent running the matting model on the GPU.
    </ResponseField>
    <ResponseField name="decode_wait_seconds" type="number">
      Time the pipeline spent waiting for the decoder to deliver frames.
    </ResponseField>
    <ResponseField name="encode_wait_seconds" type="number">
      Time the pipeline spent waiting for the encoder to accept frames.
    </ResponseField>
    <ResponseField name="scene_cuts" type="integer">
      Number of scene cuts detected. Each cut resets the temporal stabiliser's history.
    </ResponseField>
    <ResponseField name="output_bytes" type="integer">
      Size of the result file in bytes. Useful for showing download progress or checking storage before you [download it](/api-reference/video/download-result).
    </ResponseField>
  </Expandable>
</ResponseField>

Every response carries an `X-Request-ID` header.

## Status lifecycle

```
queued ──▶ processing ──▶ completed
                      └─▶ failed
```

| Status | Meaning |
|--------|---------|
| `queued` | Accepted and waiting for a worker. `progress` is `0`. |
| `processing` | Frames are being processed. `progress` increases as batches finish. |
| `completed` | Done. `result_url` is set and the result is available until `expires_at`. |
| `failed` | Processing failed. `error` says why, and the job's credits have been refunded. |

`completed` and `failed` are terminal: a job never leaves them. Every job produces exactly one terminal state.

## Polling

Poll every 2 to 5 seconds. Short clips typically finish within a minute; a 5 minute clip can take several minutes. Polling is free and does not count towards your credits. `GET` requests under `/video/jobs/` are exempt from your plan's [per-organisation rate limit](/errors/rate-limit-exceeded); only the global per-IP limit applies. Polling every 2 to 5 seconds is therefore safe on every plan, but there is no benefit in polling faster than that.

If you would rather not poll at all, pass a `webhook_url` when you submit the job and Poof will POST the job object to you when it completes or fails. See [Video webhooks](/guides/video-webhooks).

<CodeGroup>

```bash cURL
until curl -s https://api.poof.bg/v1/video/jobs/vid_8f3a1c2e9b7d4a10 \
    -H "x-api-key: YOUR_API_KEY" | grep -qE '"status": ?"(completed|failed)"'; do
  sleep 3
done
```

```python Python
import time
import requests

headers = {"x-api-key": "YOUR_API_KEY"}

def wait_for_job(status_url: str, interval: float = 3.0) -> dict:
    while True:
        r = requests.get(status_url, headers=headers)
        r.raise_for_status()
        job = r.json()
        if job["status"] in ("completed", "failed"):
            return job
        print(f"{job['status']} {job['progress']:.0%}")
        time.sleep(interval)

job = wait_for_job("https://api.poof.bg/v1/video/jobs/vid_8f3a1c2e9b7d4a10")
if job["status"] == "failed":
    raise RuntimeError(f"{job['error']['code']}: {job['error']['message']}")
print("Download from", job["result_url"], "before", job["expires_at"])
```

```typescript TypeScript
const headers = { 'x-api-key': 'YOUR_API_KEY' };

async function waitForJob(statusUrl: string, intervalMs = 3000) {
  while (true) {
    const res = await fetch(statusUrl, { headers });
    if (!res.ok) throw new Error(await res.text());
    const job = await res.json();
    if (job.status === 'completed' || job.status === 'failed') return job;
    console.log(job.status, `${Math.round(job.progress * 100)}%`);
    await new Promise((r) => setTimeout(r, intervalMs));
  }
}

const job = await waitForJob('https://api.poof.bg/v1/video/jobs/vid_8f3a1c2e9b7d4a10');
if (job.status === 'failed') throw new Error(`${job.error.code}: ${job.error.message}`);
console.log('Download from', job.result_url, 'before', job.expires_at);
```

## Error Responses

| Status | Code | Description |
|--------|------|-------------|
| 401 | `authentication_error` | `x-api-key` missing or not recognised |
| 404 | `job_not_found` | No job with this ID, or the job belongs to another account |

See [API Error Codes](/errors/list) for the error body format.
