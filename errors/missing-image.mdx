**HTTP Status:** 400

```json
{
  "code": "missing_image",
  "message": "No input provided. Send multipart/form-data with a 'file' part or a 'url' field.",
  "request_id": "req_3f6a2c1e-9b0d-4e7a-8c21-5d1f0a9b7e42",
  "doc_url": "https://docs.poof.bg/errors/missing-image"
}
```

## Reasons and How to Fix

### No File or URL Provided

The `/remove` endpoint requires exactly one input: a `file` part (image or video) or a `url` field. The legacy names `image_file`, `image_file_b64` and `image_url` are still accepted and mean the same thing. This error is returned whenever none of them is present, for images and videos alike.

```bash
# ❌ Wrong - no image
curl -X POST https://api.poof.bg/v1/remove \
  -H "x-api-key: pk_your_api_key"

# ✅ Correct - upload a file
curl -X POST https://api.poof.bg/v1/remove \
  -H "x-api-key: pk_your_api_key" \
  -F "file=@photo.jpg"

# ✅ Correct - or give a public https URL
curl -X POST https://api.poof.bg/v1/remove \
  -H "x-api-key: pk_your_api_key" \
  -F "url=https://example.com/photo.jpg"
```

### Wrong Content-Type

The request must use `multipart/form-data` encoding, even when you only send `url`.

```bash
# ❌ Wrong - JSON body
curl -X POST https://api.poof.bg/v1/remove \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/photo.jpg"}'

# ✅ Correct - multipart/form-data
curl -X POST https://api.poof.bg/v1/remove \
  -H "x-api-key: pk_your_api_key" \
  -F "url=https://example.com/photo.jpg"
```

### Wrong Field Name

The file part must be named `file` (or the legacy `image_file`); a URL goes in `url` (or the legacy `image_url`).

```bash
# ❌ Wrong field name
-F "image=@photo.jpg"
-F "video=@clip.mp4"
-F "photo_url=https://example.com/photo.jpg"

# ✅ Correct
-F "file=@photo.jpg"
-F "file=@clip.mp4"
-F "url=https://example.com/photo.jpg"
```

### Empty File

An empty `file` part (0 bytes) is treated as missing. Check that the file exists and that you are sending its contents (`@photo.jpg`), not the literal path.
