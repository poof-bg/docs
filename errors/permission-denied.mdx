**HTTP Status:** 403

```json
{
  "code": "permission_denied",
  "message": "This endpoint is not included in your current plan.",
  "request_id": "req_3f6a2c1e-9b0d-4e7a-8c21-5d1f0a9b7e42",
  "doc_url": "https://docs.poof.bg/errors/permission-denied"
}
```

## Reasons and How to Fix

### Feature Not in Your Plan

Your API key is valid, but the endpoint or feature you called is not part of your current plan.

**To fix:**
1. Check your plan with the [`/me` endpoint](/api-reference/account) or at [dash.poof.bg](https://dash.poof.bg)
2. Upgrade to a plan that includes the feature
3. Contact [support@poof.bg](mailto:support@poof.bg) if you believe your plan should include it

### API Key Not Permitted

The key may have been revoked or is not allowed to call this endpoint. Log into [dash.poof.bg](https://dash.poof.bg), check that the key is still active, and generate a new one if needed.

## Need Help?

Contact us at [support@poof.bg](mailto:support@poof.bg) with your `request_id`.
