title: Job Not Found
description: "Unknown job ID, or the job has expired"
---

**HTTP Status:** 404

```json
{
  "code": "job_not_found",
  "message": "No job with id 'job_8f3a1c2e9b7d4a10' was found, or it has expired.",
  "request_id": "req_3f6a2c1e-9b0d-4e7a-8c21-5d1f0a9b7e42",
  "doc_url": "https://docs.poof.bg/errors/job-not-found"
}
```

## Reasons and How to Fix

### Job Has Expired

Video results are kept for **24 hours after completion** (`expires_at` on the [job](/api-reference/jobs)). After that the output is deleted from the CDN, `result_url` stops working, and `GET /jobs/{id}` returns `404`.

**To fix:**
1. Download results promptly, ideally as soon as the job completes
2. Copy the file to your own storage if you need it for longer
3. Submit the video again to get a new job. It is billed again

### Wrong or Mistyped Job ID

Job IDs start with `job_` and are returned as `id` in the `202` response to [`POST /remove`](/api-reference/remove-background#video) for a video. Check that you are using the full ID and not, for example, the `request_id`.

```bash
# ❌ Wrong - request_id is not a job id
curl https://api.poof.bg/v1/jobs/req_3f6a2c1e-9b0d-4e7a-8c21-5d1f0a9b7e42 \
  -H "x-api-key: pk_your_api_key"

# ✅ Correct
curl https://api.poof.bg/v1/jobs/job_8f3a1c2e9b7d4a10 \
  -H "x-api-key: pk_your_api_key"
```

The easiest way to avoid mistakes is to use the `status_url` from the `202` response verbatim, and the `result_url` from the completed job.

### Job Belongs to Another Account

Jobs are scoped to the API key's organisation. A job created with one organisation's key is not visible to another and returns `404`, not `403`.
